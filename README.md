# DAYFLOW — édition mobile iPhone

Cette édition conserve les fonctions de l'application et ajoute une interface mobile adaptée à iPhone : navigation basse accessible au pouce, bouton d'ajout flottant, formulaires en panneau inférieur, prise en compte des zones de sécurité iOS et champs adaptés au clavier mobile.

## Tester
- Ouvrir `index.html` dans un navigateur pour un test local.
- Pour installer comme application sur iPhone : publier le dossier sur HTTPS (par exemple GitHub Pages), ouvrir le site dans Safari, toucher **Partager**, puis **Sur l'écran d'accueil**.

Les données restent enregistrées localement dans le navigateur de l'appareil. L'assistant intégré est une aide locale, pas un service IA distant.
